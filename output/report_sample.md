# 6. 评测结果对比与分析

## 6.1 云端原始模型与边缘端量化模型精度对比

| 指标         | 原始模型 | 量化模型 | 变化值   | 变化率    | 分析                           |
| -------------- | --------: | --------: | -------: | --------: | ------------------------------ |
| mAP@0.5       | 0.6231   | 0.6024   | -0.0207  | -3.32%    | mAP@0.5 下降，但变化幅度较小。  |
| mAP@0.5:0.95  | 0.4512   | 0.4387   | -0.0125  | -2.77%    | 目标检测精度在更宽的 IoU 范围内略有下降。 |
| Precision     | 0.7842   | 0.7655   | -0.0187  | -2.39%    | 精确率轻微下降，表明误检率可能有所增加。 |
| Recall        | 0.5103   | 0.4919   | -0.0184  | -3.61%    | 召回率略有下降，意味着漏检率可能提升。     |

**分析：**

量化模型在所有评估指标上均有所下降，但变化幅度较小。mAP@0.5 和 mAP@0.5:0.95 下降表明目标检测精度在不同的 IoU 范围内都有所降低；Precision 稍微减少意味着误检率可能增加，而 Recall 的轻微下滑则显示模型可能存在更多的漏检现象。尽管量化导致了性能损失，但变化幅度相对较小，说明该模型仍然基本保留了原始模型的检测能力。然而，考虑到部署价值，若量化能显著改善推理速度、减小模型体积或降低功耗等其他方面，可以认为精度的轻微下降是可接受的，并具有进一步部署验证的价值。未来工作可能需要关注针对量化后性能变化进行优化的方法以提升检测效果。

## 6.4 推理性能分析

| 分析维度 | 测试结果            | 分析                                                                                   |
|----------|---------------------|----------------------------------------------------------------------------------------|
| FPS      | 20.97 帧/秒         | 模型在处理单张图片时的吞吐量为每秒20.97帧，适合对实时性要求中等的应用场景。                     |
| 预处理耗时   | 2.290 ms            | 图像预处理时间较短，占总延迟比例较低，优化空间不大。                                               |
| 模型推理耗时 | 43.047 ms           | 模型推理耗时较长，是整体延迟能力的主要瓶颈，应考虑模型剪枝或硬件加速器优化。                       |
| 后处理耗时   | 2.359 ms            | 后处理时间相对较少，可进一步减少以提高整体性能，但优化空间不大。                                     |
| CPU 利用率   | 47.2%               | CPU利用率为中等水平，在边缘设备上表现出一定的计算负载能力，未接近上限，具备一定弹性。                     |
| GPU/NPU 利用率| 未采集到数据         | 缺少GPU/NPU利用率的数据，无法评估硬件加速器的使用情况及优化潜力。                                     |
| 内存占用     | 358.5 MB            | 单张图片推理时内存占用适中，在边缘设备上具备较好的资源效率，但仍需关注高并发下的资源消耗情况。              |

**综合分析：**

该YOLOv8n模型在单图推理场景下表现出了每秒20.97帧的处理吞吐量，整体性能较为均衡，但主要耗时集中在模型推理阶段（43.047ms），这表明优化工作应重点放在提升模型推理效率上。预处理和后处理时间较短，分别为2.290ms和2.359ms，对总体延迟的贡献较小。在CPU利用率为47.2%的情况下，硬件资源使用合理，但因缺乏GPU/NPU利用率数据，无法评估其优化潜力。内存占用为358.5MB，在边缘设备上表现适中。结合整体推理性能与资源开销来看，该模型适用于对实时性要求较高的应用场景，通过进一步压缩或加速可以提升在高负载下的表现。
